# Obsidian Course Reading｜Obsidian 课程文献阅读助手

将课程 PDF 整理为 Obsidian 中可编辑的阅读正文与课堂导读，按课程和周次归档，并通过原文链接回到 PDF 对应位置。

一周有两三篇 reading，课前需要先理解文章，课堂上需要找到概念和实验细节，学期末还要想起哪些课内文献讨论过某个问题。这个工具围绕这些场景组织阅读材料，让每篇文章留下能继续阅读、讨论和回看的笔记。

## 它能帮你做什么

### 把阅读材料整理进 Obsidian

在支持本地操作的 Agent 中，将正文、导读、原始 PDF 和图片整理到指定 vault，沿用“学期 → 课程 → 阅读 → 周次”的组织方式。每篇文章的 Reading 与 Guide 分开保存，可以并排打开、独立滚动。

正文使用可编辑的 Markdown，保留文章结构、图表与图注，支持在 Obsidian 中继续高亮和记笔记。修订已有内容时保留用户批注。具备相应工具和权限时可自动保存并打开笔记；无法直接接入时导出文件包供手动导入。

### 按阅读语言选择单栏或双语对照

中文文献配合中文阅读偏好，正文与导读全部使用中文，不额外生成英文。外语文献可生成原文与译文对照，也可以选择单语阅读。

双语 Guide 的研究设计、关键论证与发现、结论等内容都保持对应；文章结构图使用你的阅读语言，避免节点过长。如果已有其他 AI 或翻译工具生成的译文，可以与原始 PDF 一起提供，减少重复翻译工作。

### 先建立整体感觉，再看文章细节

Guide 从“先知道这篇文章在讲什么”开始，用连贯的叙述交代文章关心的现象、问题、切入方式和大致回答，让你在读原文之前先建立理解框架。

随后梳理作者回应了哪些学者或观点、使用了什么概念、怎样展开论证，以及主要发现靠什么证据支持。文章结构图覆盖整篇的主要脉络，在关键处适度展开。

### 单独讲清楚研究设计

研究设计独立成节，按文章类型说明场景或田野点、样本量、抽样与进入方式、持续时间、概念操作化、数据收集及分析过程。

实验研究关注分组、对照、操纵和测量；定性研究关注访谈、观察、田野进入与解释过程；混合方法说明各部分怎样衔接。理论文章采用合适的“材料与论证路径”，不硬套实验模板。重要信息原文没有交代时，明确注明。

### 从导读回到原文

关键概念、研究设计、不同实验和主要发现附上对应的 PDF 位置。在 Obsidian 中可以通过链接跳到相关起始页，核对上下文和证据。

对话式 AI 使用方式保留可核实的页码、章节或定位短语；无法确认页码时不编造跳转位置。

### 给课堂讨论与后续复习留下空间

每篇 Guide 包含 1—3 个针对具体论证的反思问题，以及五个带答案的快速回忆问题。额外的专业分析放在可选的“你可能还想知道”中，按主题展开，由你决定是否阅读。

最后保留空白的“我的记录”，容纳个人思考与课堂笔记。学期末可以通过导读中的主题、概念和争论线索，快速判断哪些文章值得重新打开。

## 会生成什么

| 输出 | 内容与用途 |
| --- | --- |
| **Reading／原文阅读** | 完整的实质性正文、图表与来源链接；按语言模式采用单栏或双语对照，供继续阅读和批注。 |
| **Guide／导读与笔记** | 导读、核心问题、背景争论、关键概念、研究设计、文章结构与发现、结论、可选补充分析、讨论问题、五个回忆问答和个人记录区。 |
| **原始 PDF 与图片** | 与笔记一起组织，支持核对原文和显示图表。 |

Agent 使用方式生成整套阅读资料；对话式 AI 入口默认只生成 Guide。无需使用 Obsidian，也能获得相同基线内容的导读，具体排版和交互效果取决于使用工具。

本工具服务于理解和复习，不生成可直接提交的课程作业。

## 如何使用

选择下面适合你的入口：能安装 Skill 的 Agent 用户使用第一种；在聊天工具中上传 PDF 的用户使用第二种。

### 方式一：Agent 安装与使用

适合能够使用 Skills、读取文件并执行本地操作的 Agent 环境。

Skill 目录：[skills/obsidian-course-reading](skills/obsidian-course-reading/)。安装时只选择这个子目录，不需要下载或加载 `chat/`。具体安装操作按你的 Agent 平台进行；安装时指定本仓库中的 `skills/obsidian-course-reading` 子目录。

安装后，提供 PDF，并说明课程、周次、阅读语言和目标 Obsidian vault。例如：

> 使用 obsidian-course-reading 处理这篇课程文献。课程是社会研究方法，第 3 周，我的阅读语言是中文，请保存到我指定的 Obsidian vault。

在工具和权限允许时，生成完整原文阅读笔记及导读、保存到 vault 并打开笔记。没有本地写入或应用操作能力时，可导出文件包供手动导入。其他 PDF 处理或专业分析 skill 可按需复用，不是固定安装依赖。

### 方式二：对话式 AI 使用指南

适用于在 ChatGPT、DeepSeek、元宝、千问、Claude、Gemini 等工具中上传文献、直接生成课程导读。请选择支持文件上传和 PDF 阅读的使用模式；具体能力以当前工具为准。

1. 下载 [课程文献导读指令.md](chat/课程文献导读指令.md)。在 GitHub 文件页面使用下载原始文件功能；也可以复制文件全部内容。
2. 将指令文件与原始 PDF 一起上传。无需安装 Skill，也无需下载 Agent 目录、CSS 或其他配置。
3. 可选附上课程名称、当周主题及已有译文。
4. 发送下面这段指令：

> 请按照《课程文献导读指令》为我生成这篇文章的 Guide。我的阅读语言是中文。请先确认你能读取正文、图表和 PDF 分页；能确认的位置请提供原文回溯，不能确认的不要编造。

中文文献与中文阅读偏好默认全中文。外语文献默认双语；可主动要求单语。已有译文可以与原始 PDF 一起提供，以减少重复翻译工作，实际节省取决于译文质量和对齐情况。

导读可在对话中阅读，或复制为 Markdown 笔记。支持文件生成的工具也可以输出 `.md` 文件。折叠问答、图示和本地 PDF 跳转的展示取决于软件；聊天环境至少提供可核实的页码、章节或原文定位短语，不承诺自动写入 Obsidian。

## 维护说明
